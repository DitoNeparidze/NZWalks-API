NZWalks REST API
A Guided Learning Project focused on implementing ASP.NET Core enterprise-level best practices and advanced architectural concepts.

🚀 Key Features Implemented:
Error Management: Built a custom Middleware for Centralized Global Exception Handling to ensure secure and standardized API responses.

Structured Logging: Integrated Serilog for advanced monitoring (Console and Rolling File sinks).

Architecture: Applied the Repository Pattern and Dependency Injection for clean, decoupled code.

Security: Configured JWT Authentication and Authorization.

Tech Stack: ASP.NET Core 8, Entity Framework Core, SQL Server, AutoMapper.
